SOANE Visual Trends Lab

Política de Privacidade

Última atualização: 22 de junho de 2026

Esta política descreve como o SOANE Visual Trends Lab trata dados durante o uso de uma ferramenta interna de análise de tendências visuais. O aplicativo não publica Pins, não automatiza publicações e opera apenas com dados autorizados por APIs oficiais.

1. Sobre o aplicativo

O SOANE Visual Trends Lab é uma ferramenta de análise usada para estudar tendências, palavras-chave, intenção de busca visual e oportunidades de conteúdo a partir de dados autorizados pelas plataformas. Nossa abordagem prioriza controle humano e transparência no tratamento de dados.

2. Dados que podem ser tratados

  • Palavras-chave e tendências retornadas pela API do Pinterest.
  • Métricas agregadas de crescimento, interesse ou desempenho quando fornecidas pela API.
  • Filtros escolhidos pelo usuário, como região, tipo de tendência e limite de resultados.
  • Arquivos exportados localmente em CSV, JSON ou Markdown.
  • Token de acesso do Pinterest, quando configurado pelo próprio usuário em ambiente local.

3. Dados que não coletamos

  • Senhas do Pinterest.
  • Dados financeiros.
  • Dados sensíveis de usuários.
  • Conteúdo privado de contas Pinterest.
  • Informações de navegação fora do uso autorizado da API.

4. Como os dados são usados

  • Visualizar tendências do Pinterest.
  • Classificar intenção visual de palavras-chave.
  • Calcular scores exploratórios de oportunidade visual.
  • Gerar gráficos e relatórios internos.
  • Exportar resultados para análise futura.

5. Compartilhamento de dados

O SOANE Visual Trends Lab não vende, aluga ou compartilha dados pessoais com terceiros. Dados exportados pelo usuário ficam sob responsabilidade do próprio usuário e são destinados apenas ao seu uso.

6. Armazenamento

O aplicativo pode salvar arquivos locais de exportação. O token de acesso, quando usado, deve ser armazenado pelo usuário em arquivo de ambiente local e não em repositórios públicos.

7. Uso da API do Pinterest

Quando configurado com um token válido, o aplicativo acessa endpoints oficiais da API do Pinterest para consulta de tendências. O uso segue as políticas e limitações da API.

8. Publicação de conteúdo

O aplicativo não cria, agenda, publica, edita ou remove Pins automaticamente. Qualquer funcionalidade de publicação exige ação explícita do usuário e consentimento apropriado.

9. Segurança

Recomendamos que tokens, chaves e credenciais sejam mantidos em arquivos de ambiente locais, fora de repositórios públicos. O usuário é responsável por proteger suas próprias credenciais.

10. Direitos e solicitações

Caso você tenha dúvidas sobre esta política ou queira solicitar remoção de dados exportados sob controle da SOANE, entre em contato pelo canal oficial informado pela organização.

11. Alterações nesta política

Esta política pode ser atualizada para refletir mudanças no aplicativo, nos requisitos da API do Pinterest ou em práticas internas de privacidade.
